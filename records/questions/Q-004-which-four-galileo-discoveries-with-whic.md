## Current clue references (2026-10-05)
The note draft uses month/year labels verified against the
[Rice University Galileo timeline](https://galileo.library.rice.edu/chron/galileo.html).
Galileo's lunar observations begin on November 30, 1609; Jupiter's satellites
were identified through January 1610 observations. Saturn's unusual appearance
was observed in July 1610; he did not identify it as rings. Verification of
Venus's phases is recorded in December 1610. This keeps the existing object
order and code while avoiding unsupported day precision in the note.

## Superseded date shorthand
The earlier answer used Nov 30, 1609; Jan 7, 1610; Jul 25, 1610; and Oct 1610.
July 25 was not verified in this session's checked sources. October is the start
of Venus observations, rather than the December verification represented by
the current note. These references are preserved here as history.
