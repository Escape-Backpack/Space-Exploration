## How it works
1. The uncle's note (PP-007) carries all four dated observations and a telescope
   optics sketch that introduces magnification. The designer chose note-only
   information on 2026-10-05 (Q-007); the previous card/note split is superseded.
2. Under the magnifier (PP-006), each of those objects on the sky map (PP-005) has a tiny digit next to it.
   The four objects are drawn as recognisable symbols (crescent Moon, Jupiter with moons,
   ringed Saturn, Venus), not labelled by name.
3. Putting the digits in the order of the discovery dates gives the 4-digit code.

Teaches a bit of Galileo history, plays with "looking at the sky", and needs reasoning for the order.

Not the first lock of the game: it needs equipment that has to be stored somewhere,
for example behind an earlier lock (Q-003).

Decided: many decoy digits on ordinary stars too (about 8-12), so only the digits next to
Galileo's four objects count. Decoys blend into the sky map's natural clutter of stars,
rather than reading as a deliberate grid. Digits stay tiny (~2pt, per PP-005), readable
only under the magnifier (PP-006) - needs a real test print to confirm legibility at that size.

The four observations (Q-004), in date order: Moon's mountains and craters,
Jupiter's four moons, Saturn's strange appearance, and Venus's phases.
The note uses sourced month/year references documented in Q-004; earlier exact-day
and October-discovery shorthand is retained there as superseded history.
Each object's hidden digit is arbitrary; the dates only set the order
the player arranges them in.

Decided on 2026-10-04: Moon = 8, Jupiter = 2, Saturn = 4, Venus = 7.
The answer follows the discovery order above.

Open: print size, difficulty, and whether the player map itself hints at the order.
AS-003 now supplies a numbered player draft with answer digits and decoys.
Its physical print size, glyph size and magnifier readability still need testing.
The annotated solution companion is documented in AS-003 and is for designer review only.
