## Current - 2026-11-21
The designer's preferred "standard" print sizes, chosen so the game could be commercialized.
Design each printed item to one of these sizes:

| Item | Size (inches, as given) |
|---|---|
| Flyer | 5.5 x 8.5 |
| Postcard | 4 x 6 |
| Bookmark | 2 x 6 |
| Business card | 3.5 x 2 |

Word print files follow the Raven Inheritance structure (Norse-Expedition/Print): Letter
portrait page, one exact-size picture per page, print at 100% / Actual size.

## Where the game does not match yet
Not yet checked item by item. Known so far: the star chart (AS-021) is 8 x 8 in, not a
standard size; the observation note (AS-028) is 4 x 6, a postcard. Resizing the chart is
not decided.
